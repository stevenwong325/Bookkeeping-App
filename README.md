# Bookkeeping App

A modern web application for tracking personal income and expenses, built with React and Tailwind CSS.

## Features

-   Track income and expenses
-   Categorize transactions
-   Filter transactions by type, category, and date range
-   Export transactions to CSV
-   Responsive design
-   Local storage for data persistence

## Technologies Used

-   React
-   Tailwind CSS
-   Local Storage API

## Getting Started

### Prerequisites

-   Node.js (v14 or higher)
-   npm (v6 or higher)

### Installation

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/bookkeeping-app.git
cd bookkeeping-app
```

2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm start
```

The app will be available at `http://localhost:3000`

### Building for Production

To create a production build:

```bash
npm run build
```

## Usage

1. Add new transactions using the form at the top of the page
2. Filter transactions using the filter section
3. Edit or delete transactions using the action buttons
4. Export your transactions to CSV using the export button
